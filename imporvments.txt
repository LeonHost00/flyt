19. Token Deduction Race Condition (TOCTOU)
Location: 
main.js:541-605

Issue: `deductTokens` fetches the balance, calculates the new value locally, and then updates it. This is a classic race condition. If multiple AI requests process simultaneously, one deduction will likely overwrite the other, leading to inaccurate token billing.

Recommendation: Use a Supabase RPC function to perform an atomic decrement in the database: `UPDATE user_profiles SET tokens = tokens - amount WHERE id = userId`.

20. Insecure Storage of API Keys
Location: 
supabase/migrations/20260111100000_add_app_settings.sql

Issue: The `app_settings` table has a `USING (true)` policy for `SELECT`. Since `openrouter_api_key` is stored here, any authenticated user can potentially query and steal the global API key.

Recommendation: Move sensitive keys to a dedicated `secrets` table with restricted RLS (service_role only) or use Supabase Vault.

🟠 HIGH Issues
21. Session Loss on Machine Identifier Changes
Location: 
main.js:73-103, 178-209

Issue: `getMachineEncryptionKey` relies on `os.hostname()` and `os.userInfo().username`. If a user renames their computer or changes their OS username, the encryption key changes. The app then detects a decryption failure and *automatically deletes the entire store file*, forcing the user to log in again.

Recommendation: Use a more stable unique identifier (like hardware UUID) or handle decryption failures more gracefully without immediate data deletion.

22. Inefficient pure JS SearchFilesTool
Location: 
tools/filesystem.js:492-637

Issue: `SearchFilesTool` uses a manual recursive traversal in Node.js. In projects with many files (e.g., node_modules), this will be extremely slow and block the main process.

Recommendation: Use a more optimized library or delegate to native tools like `rg` (ripgrep) which is significantly faster.

🟡 MEDIUM Issues
23. Lack of Database Transactions for Tokens
Location: 
main.js:541-605

Issue: Updating the user's token balance and recording the transaction in `token_transactions` are separate asynchronous calls. If the second call fails, the transaction history will not match the actual balance.

Recommendation: Use a database transaction or a single RPC function to ensure both operations succeed or fail together.

24. Auto-Launch Enabled by Default
Location: 
main.js:2501-2510

Issue: The app automatically enables itself to start with Windows/OS upon first run without asking the user. This can be perceived as intrusive.

Recommendation: Add a setting or an onboarding step where the user explicitly opts in to auto-launch.
